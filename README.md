최효재의 실제 개인 작품, 회사 프로젝트 경력, 현재 YIGO.에서 기획·개발 중인 Aelin을 소개하는 로컬 브랜드 페이지입니다. 메인 표기는 **Jay.**, 서브타이틀은 **on the art**, 현재 활동 표기는 **YIGO. · Creative Leader**입니다. Resume에는 **YIGO. 대표이사 · 재직 중**이라는 실제 경력 사실을 유지합니다. `SYNFORM`, `Artweaver Jay / AJ`가 남아 있는 경로·파일명은 이전 작업 기록입니다.

**현재 상태 · 2026-10-13:** 승인된 1차 리뉴얼의 메인 페이지·스크롤 장면·영상 슬롯·프로젝트 탐색·클래식 Resume 구현을 마쳤습니다. 메인·Resume의 대표 화면과 주요 탐색·영상·모션 동작을 로컬 브라우저에서 확인하고 발견한 표시·접근성 문제를 수정했습니다. 외부 배포·공개는 실행하지 않았습니다.

## 현재 미리보기

- [Jay. 브랜드 페이지](http://127.0.0.1:4174/)
- [최효재 Resume](http://127.0.0.1:4174/resume.html)

**4174 포트가 최신 미리보기입니다.** 영상 MIME과 바이트 범위 요청을 지원하는 현재 서버를 사용합니다. 4173 포트의 이전 프로세스는 그대로 유지했으며 영상이 포함된 이번 리뉴얼 확인에는 4174 주소를 사용합니다.

서버를 다시 시작할 때는 Node.js와 npm이 있는 PowerShell에서 다음을 실행합니다. 4174 서버가 이미 실행 중이면 기존 서버를 사용합니다.

```powershell
Set-Location -LiteralPath 'F:\_Final\_이력서\_라이온하트\SYNFORM-브랜드페이지'
npm install
npm run build
$env:PORT = '4174'
npm run dev
```

- `npm install`: Three.js, esbuild, sharp를 설치합니다. 의존성이 이미 설치되어 있고 변경되지 않았다면 생략할 수 있습니다.
- `npm run build`: `cosmos.js`를 브라우저용 번들로 만들고 `assets/`의 PNG·JPG에서 최적화된 WebP를 생성합니다. 원본 이미지는 보존합니다.
- `npm run dev`: 현재 `PORT` 설정의 `127.0.0.1` 주소에만 서버를 엽니다. `PORT`를 지정하지 않으면 기본값은 4173입니다.

HTML·CSS·`app.js`는 수정 후 새로고침으로 확인합니다. `cosmos.js`나 원본 이미지가 변경되면 먼저 빌드합니다. 현재 빌드 명령은 영상 편집·인코딩을 자동으로 수행하지 않습니다.

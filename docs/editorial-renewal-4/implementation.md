# Jay 브랜드 페이지 편집 리뉴얼 구현 기록

2026년 10월 14일. [수정 명세](spec.md)와 [확정 문구](copy.md)에 따른 로컬 구현을 완료했다. 기준 커밋은 `769b149`이며 이번 변경은 커밋·푸시하지 않았다.

## 추가 크기와 Resume 수정

같은 날 추가 요청에 따라 홈 로고는 직전 크기의 2.5배, 헤더와 홈 푸터 로고는 0.6배로 조정했다. 홈 핵심 문장은 데스크톱 32px·모바일 28px이며 소개 문단은 제목과 같은 잉크색이다. 경력 회사·역할·본문은 각 1px 낮췄다. Font 참조 값도 함께 갱신했다.

프로젝트 타임라인은 타일 전경에서부터 나타난다. 카드 간격은 0.65 화면 높이로 줄였으며 마지막 MORAI를 읽는 구간 뒤 02 영상이 위를 덮으며 진입한다. 페이지 하단에서 헤더가 사라지고 역방향에서 복원된다. 모든 사이트 ArtStation 클릭 링크는 `https://www.artstation.com/jayontheart`로 통일했다. 원본 자료 출처 URL은 보존한다.

Resume는 사용자가 제공한 20년 경력·AI 응용·API 활용·개인 프로젝트·아트워크·출시 계약·상용화 문구를 반영했다. 회사 사정에 따른 종료 표현과 하단 두 footer를 제거하고 흰 지면으로 정리했다. 대표이사 재직 표기는 유지한다. 데스크톱에서 타임라인의 이른 표시, MORAI 영상 덮기, 헤더 숨김·복원, Resume 새 본문과 흰 하단을 확인했다.

## Resume 연결과 최신 워드마크

후속 Resume 연결 수정에서는 흰 헤더에 `제이온더 아트`를 표시하고 하단 지면 여백을 100px, 모바일 80px로 늘렸다. 홈의 한글 표기도 히어로에서 상단 헤더로 옮겼으며 홈과 Resume 모두 16px·650 굵기·1.6 줄높이·-0.04em 자간으로 맞췄다. 본문 워드마크는 ‘웹 인터랙티브 레퍼런스 조사’ 세션에서 전달한 `*-rounded.svg` 최신 가로형·좌측 정렬 세로형으로 교체했다. 원본 비율을 유지하고 필요한 밝은 색·색상 상속 변형을 함께 만들었다.

공통 자간 규칙은 W3C 한글 조판 요구사항의 기본 0 간격을 출발점으로 삼고, 화면용 본문은 -0.012em, 제목은 -0.04em, 대형 제목은 -0.055em으로 미세하게 조인다. 작은 메타 정보는 판독성을 위해 +0.075em 이하로 제한하고 기존의 과한 넓은 자간을 낮췄다. 규칙은 `design-tokens.css`와 `font.html`에 함께 반영했다.

메인에서 Resume는 dialog 안의 독립 문서로 열리며 닫기·Escape로 복귀한다. `경력 상세 보기`는 회사 프로젝트 타일 전경, `YIGO. / Aelin`은 02 섹션으로 부드럽게 이동한다. 별도 Resume 주소에서도 같은 목적지로 진입한다. 팝업 이동 메시지는 같은 출처의 해당 iframe에서만 처리한다. 영상의 임시 안내 화면 문구와 Discover의 credit 줄을 제거했고 헤더 Practice는 Project로 변경했다. 팝업 열기와 세 목적지 이동, 동일한 한글 타이포와 Resume 헤더의 흰색을 브라우저에서 확인했다.

## 최초 편집 구현

- 두 로고의 투명 path SVG v3를 홈·헤더·푸터·Resume에 적용했다. 가로 비율은 기존의 0.94, Jay 윤곽은 같은 비율의 이전 버전보다 잉크 면적 약 8.3% 감소했다. 닷은 원형과 `#FF616B`를 유지한다. 홈 대표 로고만 이전 렌더링 폭의 20%이며 1280px 화면에서 76.8px, 모바일에서 58px다.
- 확정 카피를 전면 반영했다. 홈의 외부 링크를 제거하고 이름·영문 전문 영역·핵심 문장·설명으로 구성했다. 헤더는 홈에서 숨겨지고 00 진입 때 나타난다. 키보드 초점은 숨은 헤더를 표시한다.
- `font.html`을 헤더와 모바일 메뉴에 연결했다. `design-tokens.css`와 `editorial-type.css`를 공유하며 글꼴, 크기·굵기, 색, 여백, 투명 로고와 링크 상태를 설명한다.
- POV는 88–112px 코랄 원에서 출발해 영상이 나타나며 전체 화면으로 확장한다. 역방향에서는 다시 영상이 보이지 않는 코랄 원으로 돌아온다.
- 회사 프로젝트 10개를 시작월 순서로 재정렬했다. 같은 2006년의 두 프로젝트와 겹치는 기간은 그대로 보존한다. 우측 연도축은 실제 시작월·종료월과 현재 카드에 연결되며, 화살표·Home·End와 Enter로 탐색한다. 카드 간격은 1.12에서 0.9 화면 높이로 줄였고 기존 프로젝트 해시는 ID로 해석한다.
- Discover는 01 Marakun: Design Theme → 02 Marakun: Flame of the Dusk → 03 To The Brink → 04 Reconstruction → 05 Mansion : 3F → 06 Sketching Ideas 01 순서다. 첫 두 타이틀의 접미 문구는 기본 제목보다 10% 작게 표시한다. 모든 카드의 이미지와 제목 링크는 순서에 맞는 artwork URL을 사용한다.
- 경력은 하나의 고정 화면에서 두 제목이 이동 없이 페이드로 교체된다. 이후 네 회사 묶음을 일반 세로 흐름으로 읽는다. `#career` 직접 링크를 유지하고 실제 문서 위치로 배경 카메라 경로를 계산한다.
- SCAN → FRAME → BUILD → EVALUATE와 새 프로필·마지막 문구를 적용했다. 프로필 소속은 `YIGO · Creative Leader`, 본문과 다른 정식 소속은 `YIGO.`다. Resume의 대표이사 재직 사실은 유지한다.

## Reconstruction 자료

[지정 원본](https://www.artstation.com/artwork/obaDnW)의 현재 게시물 제목은 `#SketchingIdeas 02`다. 사이트에는 사용자가 정한 `Reconstruction`을 사용한다. 해당 페이지의 실제 이미지와 경사지 재개발·모듈·이동수단·Unreal Engine 5.4/Lumen/PCG 설명을 확인했다. 이미지 출처와 표시명 관계는 `assets/reconstruction-source.json`에 기록했다.

## 확인 범위

로컬 빌드가 완료됐다. Codex 브라우저에서 데스크톱 1280×720, 모바일 너비 390px의 실제 페이지를 확인했다.

- 홈의 로고 크기, 설명 색·자간, 숨은 헤더와 00 이후 표시
- POV의 원형 시작 상태, 전체 화면 영상 재생과 역방향 원형 복원
- 회사 카드·연도축 배치, `#career-project-7`이 SHOW ROOM으로 이동, 키보드 End/Enter로 MORAI 이동
- Discover의 6개 순서·링크와 Reconstruction 실제 이미지
- 경력 공유 화면의 두 투명도와 이동 없는 전환, 네 회사 읽기 흐름
- 모바일 본문의 줄바꿈과 가로 넘침, 새 워크플로우와 Font 페이지
- 모션 끄기에서 회사 프로젝트 10개·경력 제목 모두 표시
- 주요 화면을 순회한 뒤 브라우저 오류 로그에 오류가 없음을 확인

화면에서 발견한 모바일 줄바꿈 공백, 회사 카드 번호 태그, 어두운 경력 진입의 텍스트 대비를 보완했다. 스크롤 길이에 따라 카메라 위치가 달라져도 마지막 위치가 동일한 경로에 연결되도록 기존 단일 카메라 보간기를 유지했다.

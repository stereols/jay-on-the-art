# Jay on Art 브랜드 페이지 최종 수정 구현 기록

2026년 10월 14일. [최종 수정 명세](spec.md)에 따른 로컬 구현과 변경 범위 검수를 마쳤다. 미리보기는 [http://127.0.0.1:4174/](http://127.0.0.1:4174/)다. 기존 공개 사이트를 변경하지 않았으며 커밋·푸시하지 않았다.

## 반영 내용

- **워드마크:** 공식 표기를 Jay on Art로 통일했다. 메인·Resume의 인라인 SVG와 Font 페이지의 `assets/brand/jay-on-art-*-rounded*.svg` 변형을 함께 갱신했으며, SVG 제목·설명과 접근 가능한 이름도 같은 표기를 사용한다. 사용하지 않는 이전 이름의 로고 묶음은 제거했다. 가독성을 위한 투명 카운터, 잉크색과 `#FF616B` 포인트는 유지한다.
- **색·글자·링크:** 주 배경·밝은 패널·CSS 대체 화면·WebGL 낮 배경을 `#F6F1E8` 기준으로 맞췄다. 일반 텍스트는 잉크·중립 회색, 텍스트 링크의 호버·포커스는 `#FF616B` 글자와 밑줄이다. 헤더 Resume 버튼, 로고·작품 이미지 링크, 실제 조작 버튼의 형식은 유지한다. 일반 소개 그룹은 데스크톱 22px/모바일 18px, 이미 큰 프로필 대표 소개(`.about-copy .lead`)는 38px/28px로 확대한다. 회사·기간·이미지 고지는 확대하지 않는다. 주요 왼쪽 여백 두 배, 산세리프·이탤릭 금지를 유지한다.
- **01 참여 프로젝트:** `CARD_SPAN`을 1.35에서 1.12 화면 높이로 약 17% 줄였다. 첫 마구마구는 이미지 정착 뒤 설명이 나타나고, 다음 카드들은 설명과 이미지가 함께 진입한다. 타일·이전/다음·직접 이동이 같은 카드 구간을 사용한다.
- **02:** 같은 영상 요소가 전체 화면으로 먼저 나타난 뒤 중앙 제목이 올라오고, 영상이 프레임으로 돌아온 뒤 기존 Aelin 설명으로 이어진다. 중복 소제목과 지정된 작은 문구를 제거했다. 임시 영상 고지, 포스터·직접 재생/정지·오류 안내·화면 밖 정지를 유지한다. 모바일·정적 경로는 읽을 수 있는 일반 흐름을 사용한다.
- **Discover·03·04:** Marakun 조립 소개·네 단계 UI·축소 전환을 제거했다. Marakun Modular Village부터 개인 작품 6개와 원본 링크·제작 범위 고지를 유지한다. `#marakun-explorer`는 첫 카드로 이어진다. 지정된 중앙 타원 장식·문구, Full resume 링크, 경력 이미지 아래 문구, 04 우상단 문구를 제거했다. 경력 이미지의 대체 텍스트·자산 정보에는 임시 상태를 남겼다.
- **카메라:** 문서에서 측정한 장면 위치로 하나의 스크롤 경로를 만든다. 인접 구간이 같은 끝점 데이터를 공유하고 위치·시선·회전·밤 전환·블러·밝은 오버레이를 함께 보간한다. DOM 고정 장면의 진행률과 카메라 진행을 분리했다. 경력 전환은 진입부터 줌아웃하며 최하단은 기존 위치 `[0.2, -5.5, 21]`, 시선 `[1, -5, -3]`, 회전 단계 `4.6`을 유지한다.

YIGO. 대표이사 재직, Aelin 기획·개발 중 상태, MORAI 표기, 회사 프로젝트 10개·개인 작품 6개의 사실과 순서를 보존했다. 생성형 회사 이미지·가상 인물 프로필·Aelin 임시 영상은 최종 자료로 교체할 수 있다.

# Jay. 브랜드 시스템 적용

2026-10-14. 공식 SVG 로고, 참고 이미지의 타이포그래피 위계, 넓어진 왼쪽 여백을 로컬 사이트에 반영했다.

[미리보기](http://127.0.0.1:4174/)

- 원본 가로형·세로형 SVG의 잉크 #182525, 닷 #FF616B와 투명 배경을 유지했다. 헤더·푸터는 넓은 화면에서 가로형, 모바일에서 세로형을 사용한다. 첫 화면과 Resume의 브랜드 소개는 세로형을 사용한다. SVG는 페이지 안에 넣어 Manrope 웹폰트를 사용하고 각 복제본의 ID를 고유하게 만들었다.
- brand-system.css에서 --primary를 #FF616B로 선언했다. 버튼·진행선·선택 상태에 적용하며 작은 강조 글자는 읽기 쉬운 진한 색을 사용한다. 어두운 장면의 헤더 로고에는 밝은 바탕을 제공한다.
- 주요 텍스트의 왼쪽 여백은 기존 패딩의 두 배다. 1440px 화면에서 약79→158px, 390px 모바일에서23→46px를 확인했다. 카드 설명은 이미지와 겹치지 않게 폭·위치를 함께 조정했다.
- 참고 이미지의 큰 제목·소제목·본문 구분을 반영했다. 주요 제목은 데스크톱 58–76px 범위, 보조 제목은30–40px, 본문은14–15px 중심으로 조정했다. Discover의 기존 큰 제목은 유지했다. 이탤릭은 쓰지 않는다.

데스크톱·모바일의 로고 선택, 왼쪽 여백, 가로 넘침 없음, SVG ID 중복 없음, Manrope 로딩, 어두운 장면의 로고 대비를 확인했다. Resume의 대표이사 재직 사실을 보존했다. 확인한 경로의 런타임 오류는0건이다. 최신 모바일 SCROLL 위치는 캡처 후 고정 버튼보다 위로 추가 조정했다.

캡처는 previews/brand/에 보관한다.
